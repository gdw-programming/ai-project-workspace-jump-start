# Brain/Portability Core Message

## Problem
`.ai-toolbox` is not consistently framed as the project's persistent "brain" — portable knowledge and context that travels across agents, sessions, and contributors. This framing exists in scattered rules (Project Memory Authority, External Memory Scope) but isn't the lead message where a new user or agent first encounters the system.

## Change
- Update `.ai-toolbox/README.md` intro paragraph and Core Principles to lead with: `.ai-toolbox` is the project's portable brain — the persistent memory and context that makes project knowledge travel across agents, tools, and sessions.
- Update `context.global.md` opening framing (above Definitions) to reinforce the same message in AI-facing terms.
- Reinforce the same language in `docs/Getting Started.md` so human readers get it too.

## Files to touch
- `.ai-toolbox/README.md`
- `.ai-toolbox/context.global.md`
- `.ai-toolbox/docs/Getting Started.md`
