# Plan Next Phase

**Aliases**: `plan-next-phase`
**Purpose**: Identify and prepare for upcoming work.
**Pattern**: Re-read Git and workspace state at the start of every run (see `context.global.md` Workspace State Awareness). Consult project brain in order, analyze current state, identify dependencies, prepare next steps. Before finalizing a plan intended for version control, check its linked and plain-text paths against Git's tracked and ignore status and apply Shared Plan References in `context.global.md`; carry forward relevant findings without ignored paths. If status cannot be verified, report the unresolved check.
**Context**: `context.global.md` -> `context.steering.md` -> relevant `project/`, `domains/`, `patterns/`, `tools/` contexts -> applicable commands -> `../STATUS.md` + `../BACKLOG.md` + `../CHANGELOG.md`
**Example**: Review backlog, update priorities, add next steps.
